# wlcpow: bonded WLC/power-law force with viscous and stochastic terms

The source computes directed bonded forces using a worm-like-chain-shaped elastic expression, power-law term, longitudinal/transverse viscous terms and a deterministic TEA-derived noise matrix. Positions, velocities, rest lengths and material parameters produce force increments. The repository supplies no identified application/paper establishing a particular biological material, integrator or calibration; this study certifies a numerical force building block, not a complete molecular or biological simulation.

Historical Julia contains genuine force formulas but skips native particle0, processes the ghost particleN, converts velocity.w to a scaled rounded numeric seed instead of its IEEE Int32 bits, reconstructs neighbor IDs, and uses exp(y*log(x)) instead of native powf. The source and Makefiles are archived; retrospective source/CPU witnesses are not presented as an observed old GPU run. The new CUDA.jl reference and portable versions restore actual AoS input records, i0...N-1, explicit neighbor/type arrays, padding1 flat indexing, bit seeds, four TEA rounds, native-domain no-epsilon-clamp behavior, and Float32 Base^ lowered by the pinned CUDA backend to libdevice powf. Native kernel and utils bodies are byte unchanged; no corrected-native flag applies.

## Inputs and complete numerical contract

Five named controls use N2/127/128/129/513, material-type maxima0/1/4/32/3 and repeats1/2/3/4/2. Each launch has128 threads and ceil(N/128) blocks. The source padding1 overlapping flat-bond indexing is preserved, with2N+1 physical bond slots,0...3 neighbors per local particle, a ghost atN, nonzero Float64 initial forces and positive nonsingular parameters. The chosen r0>1 domain is explicit; the original million-particle random initializer is not certified. Minimum distance is about .0716 and the minimum TEA uniform .000258, so no zero-distance/log-zero/r0=1/lambda-zero claim is made. The independent fixture exercises two extension caps and688 power-denominator floors. Gaussian ±4 clipping is implemented but not triggered, and no distribution/thermostat validation is claimed.

All20 complete52617-word artifacts pass:16648 exact input-prefix values and35969 full states. They include actual initial and final three force arrays, all13 read-only GPU inputs and every64-element prefix/suffix guard. Initial values, read-only inputs, guards, ghost and zero-neighbor forces are checked bit exactly. All payload bases remain256-byte aligned. Native float4/int2 declarations have alignments16/8; Julia's equivalent isbits structs have the same offsets and strides16/8 but declared alignment4, a disclosed code-generation covariate. Actual vector memory instructions were not profiled.

An independent Float64 oracle evaluates analytic elastic/power/viscous expressions, exact wrapped TEA rounds, source-rounded random conversions and natural-log/sine Box-Muller rather than copying native Float32 log2/sinpif instructions. The fixed engineering budget is1e-4+2e-4*abs(reference), not a formal error bound or material-physics validation. Maximum force absolute error is .0008494; maximum normalized budget use is .0466. A near-zero component has relative error .122% but absolute error only1.09e-7, so there is no uniform relative-accuracy claim. Actual per-neighbor force and neighbor accumulation are Float32, despite Float64 storage for rest lengths and final force buffers. Rest lengths are explicitly cast to Float32 before the formulas; Float32 increments are converted and added to Float64 state across repetitions.

The noise-free first case has reciprocal particle indices but different rest lengths; it does not test equal-and-opposite total force. An independent control adds the transverse damping back to each individual bond's force and verifies the remainder is radial. This projection residual is zero for all saved paths. No global momentum-conservation or full trajectory/energy claim is made.

## Mapping, timing and effort

Each block cooperatively loads eight parameter tables then synchronizes. CUDA.jl/native use dynamic shared capacity8*(nt+1)*4 bytes; KA uses the same size statically through five Val capacities, and JACC uses dynamic shared plus a whole-template initialization copy and extra entry barrier. Device indices, shared arrays and barriers use each own framework, with ordinary Base math; only host allocation/transfers/synchronization/readback rely on CUDA. Non-CUDA backends remain unverified.

The timed region sums five kernel-only repeated-accumulation intervals,12 launches total. Forces reset to their nonzero initial state outside the ROI once per case, and remain accumulated across all repetitions. Allocation, actual input/initial-force reads, full outputs, independent checks, JIT/full-kernel warmup and serialization are outside. All five trials are checked, only timing1 is discarded and2–5 averaged; per-case cumulative times are retained. There are no measured instruction/FLOP/traffic/occupancy counters or roofline conclusions.

All current Julia candidates compile and pass their first device check without repairs. Shared numerical helpers, fixture, independent oracle and adapters were authored once in reference preparation, then reused by framework-specific table loaders/dispatch. Prospective model windows include repeated/cached context, annotation/audit and coordination, including the JACC-window ANS/ASSERT ownership handoff. They overlap the workflow and are ordered marginal, not summed exclusive billed or independent cold-start framework costs. Historical creation cost remains unknown.
