Preserves no-argument1024x1024 default, SOR omega1.85, tolerance1e-6, million-iteration cap, all coefficient/boundary formulas, CPU reference, and temperature.dat format. Red/black temperatures and residual storage are iris_rw; every kernel uses its own synchronous task. CUB/hipCUB reduction is replaced with two HIP sum kernels (P1: float reduction order/performance differ), norm output flushed each phase. NUM is compile-time configurable for bounded validation; rebuild with make clean && make NUM=256, default remains1024. Native baseline uses only an ifndef NUM header guard for the same bound, original native source unmodified. Validation compares every output coordinate/temperature with HIP in isolated directories, including finite checks. CPU signed-difference criterion is preserved; full absolute HIP artifact comparison additionally required. Host reference uses OpenMP, IRIS backend remains HIP only.
