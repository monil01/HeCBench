# SPH source-equation study

This study executes all four original Float64 GPU stages (density/pressure, fluid force, boundary force, leapfrog position update). The primary named fixture retains the original 2,048 fluid particles, 4,706 boundary particles and 500 sequential steps. An isolated-particle 17-step control is supplemental. Every target retains dense interaction loops, physical 112-byte fluid/48-byte boundary AoS layout and the source boundary-count launch grid (19 blocks versus eight fluid blocks). Only the independent CPU oracle uses support-neighbor pruning.

## Numerical and scientific scope

The independently expressed CPU evaluator uses radial coefficients, a support-neighbor search with source-order summation, and full state checks. Every saved artifact is audited against full 14-field final CPU results, selected complete untimed warmup states, both available GPU references, exact device input bytes, tail guards and readonly boundary/parameter storage. Density must stay positive and all fluid fields finite. The declared coarse central envelope is insufficient alone; audit_saved.py applies the predeclared field budgets from study_plan.json.

A single actual untimed warmup trajectory per model process supplies the checkpoint trace. Its bytes appear in that process's five artifacts. This does not represent five independently captured warmup traces or all overwritten timed intermediate states.

This is source-equation translation fidelity, not a validated physical fluid simulation. The isolated gravity witness shows the source half-velocity initialization has an extra one-step velocity offset relative to a zero-initial-velocity continuum solution. The original GPU bodies and this startup behavior are preserved. The source boolean boundary tangential gate, viscosity denominator and surface-force sign are also preserved. No full continuum conservation/convergence certificate is claimed.

## Defined-storage qualification

Original host initialization leaves initial pressure unused/uninitialized and parameter ABI trailing padding undefined. The owned input generator defines pressure and padding as zero. All mathematically read original fields and boundary bytes match actual original GPU readbacks. This qualification is recorded as a repaired/defined-storage secondary reference and excluded from untouched-native aggregates; no observed wrong 500-step original output is attributed to those unused bytes. The unchanged original CLI and full-state capture were executed separately.

## Timing

Each process first completes one untimed full trajectory, including device compilation. Each of five timed trials resets all inputs, captures the actual device input bytes, synchronizes, runs four kernels per sequential step, and synchronizes before stopping the timer. Recorded time is total trajectory duration divided by step count. These steps are coupled integration steps, not independent repetitions. Transfers, validation, final readback and warmup captures are outside the timer. Trial one is retained but excluded from the reported mean of trials two through five.

The exact runtime/library/compiler versions, attempt counts, prospective context-inclusive token windows, reproducibility recipes and finalized run receipts accompany the final support packet. GPU measurements are serialized on physical GPU6; no raw GPU capture is a Git input fixture.

## Reproduce CPU fixtures and verify saved evidence

From the source repository root, run:

    python3 src/sph-julia/regenerate_assets.py --output /tmp/sph-cold --proof /tmp/sph-cold-proof.json

This compiles the source-based CPU input generator with nvcc and the independently expressed evaluator with g++, but executes no GPU kernels. It reproduces all ten assets (2,291,072 bytes) exactly in the measured environment. asset_hashes.json specifies every byte count and SHA-256. There are no irreplaceable binary inputs. To populate an unpacked source tree, use its src/sph-julia directory as the output; the helper verifies its generated bytes against those immutable expected hashes. Reproduction on another compiler/libm platform must satisfy these hashes, not silently replace them.

The primary final result is 20261020T042914619777Z_sph and the supplemental ballistic result is 20261020T042855878298Z_sph. With NumPy available, the read-only review is:

    python3 src/sph-julia/review_evidence.py

Final audits cover all 40 selected captures, 50,403,840 bytes and every declared source/asset binding. Raw GPU captures remain local evidence, not Git fixtures. No additional accepted GPU trials were run for this final review.
