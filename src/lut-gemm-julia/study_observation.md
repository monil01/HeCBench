## Scientific intent and fidelity

Historical Julia source is dense Float32 matvec without packed planes, learned scales, offsets or LUT. Preserve it and restore actual source operator and shared lookup/packed atomic mapping in all Julia versions.

Scientific task: y[m]=sum_k x[k]*(bias[group(k),m]+sum_b alpha[group(k),b,m]*sign(W[k,b,m])). Bit sign is +1 for set bits and -1 for unset bits. Alpha is learned per group, bit plane and output; it is not a fixed power-of-two integer quantizer.. Requirements and precision sensitivity: Every output and actual input/guard value exact against independent dense integer weighted matvec. Dense quarter-integer inputs and half scales ±1/128 give all intermediate values exactly representable in half: absolute integer coefficient bound <=2048 on1/512 lattice. All32 packed bit positions active except explicit zero control.. Community use case: Source NAVER LUT-GEMM compressed-weight inference operator, useful to study learned bit-plane lookup GEMV mapping. No end-to-end model quality, quantization calibration or production inference recommendation.. Provenance/uncertainty: Original source mv_fp16.h and kernels.cu, NAVER Cloud copyright2024 Apache2.0. Source headers and full originals archived. Independent oracle expands every packed bit directly; no LUT source reuse.. Domain-neutral examples are illustrative uses, not claimed original application provenance.
