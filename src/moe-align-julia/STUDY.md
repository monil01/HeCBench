## Explicit implementation adaptations

The historical Julia used a host prefix roundtrip. The named reference restores the source small/general GPU structure. All Julia versions use an explicit1024-word Blelloch scan instead of native CUBBlockScan, an algorithm/resource adaptation that prevents attribution of a native gap solely to API overhead. Fill-only small-mode threads remain alive through all three barriers; source fill threads return after the first. This is a control-flow mapping adaptation, not an unsupported-barrier claim. Source native small mode ran correctly on the selected Volta GPU. The historical expert-label fill/write overlap remains a source-observed potential race, not an invented historical failed check.

Portable Atomix handles shared/global Int32 atomic updates; all three Julia implementations are framework device kernels, with only the CUDA backend tested.
