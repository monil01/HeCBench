# clock: genuine reduction and actual source clock register

`study_config.json` validates the unchanged native block-minimum reduction with two finite Float32 input fixtures, source threads256 and grids1/32/8192. Every block reads the same512 values, follows the source strict-less shared tree and records first-lane device clocks. The historical Julia constant-write placeholder and Makefile are archived intact; `clock-julia-cuda.jl/study.jl` is the genuine completed reference.

On this Linux/NVCC12.0 toolchain, source clock() with64-bit clock_t compiles to mov.u64 %clock64. The saved native PTX and `native_clock_instruction_witness.json` establish that fact. CUDA.jl, KA and JACC use CUDA.clock(UInt64). KA/JACC reductions/barriers/dispatch use their own APIs, while the hardware counter is a disclosed CUDA-specific backend extension. This is not a pure backend-neutral hardware timer.

Each of five checked trials saves34134 UInt32 words:1042 exact input/parameter words,16450 actual minima,192 output/timer guards and16450 independently checked timer-property bits. Raw32996 Int64 timer/guard words are retained separately for every model/trial, with paths/SHA256 in `output_audit.json`. Raw clocks are nondeterministic observations: no cross-model clock equality, cross-SM timestamp comparability or conversion to wall time is claimed. Same-block modular UInt64 elapsed must be positive and below2^31; current samples must have nonnegative clock_t representation. `audit_saved_outputs.py` independently checks every raw timer and exact minima by sorted order statistic without a GPU.
