IRIS dmem translation of the original MPI Maxwell DG solver. Legacy texture fetches become read-only dmem kernel parameters; volume, surface, RK and halo extraction kernels preserve CUDA math/layout and launch sizes. MPI exchange and mesh partition use the original unchanged C source/ParMETIS helpers. Defaults remain N=6, NP=2, FS_K01022.neu and FinalTime=0.00050 with the source's timestep override.

The default build copies bundled ParMETIS into generated .deps/ and compiles it using system MPI; alternatively set PARMETIS_ROOT to a compatible installation. The Makefile never modifies the sibling source. Only N=6 operator data is bundled upstream. Optional MINIDGS_VERIFY_DIR writes all six active nodal fields per MPI rank for independent validation. There is no native HIP sibling; use a separate CUDA-source CPU reference solely for numerical verification, never as execution fallback. Native HIP timings remain unavailable.
