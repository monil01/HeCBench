# bsearch: exact four-variant predecessor lookup

All four unchanged native kernels are checked against CUDA.jl, KA and JACC on Float32/Float64 arrays of lengths2,3,8,9,17,32,33,257,1025. Each case has512 finite queries in [a0,aN), covering exact ties, adjacent representable values and midpoints. Output indices, sentinel guards and input IEEE bits are exact, with no floating-output tolerance. Full arrays and every sorted interval are checked by independent CPU upper-bound oracles. Historical CUDA.jl BS1 remains byte-preserved except an autorun guard; three missing study variants are completed explicitly.

BS1 uses interval bisection; BS2 a guarded bit walk; BS3 a sentinel-clamped probe; BS4 shares its highest-bit seed per block. CUDA.jl and KA use one block barrier in BS4; JACC explicitly requests8 bytes and adds its framework shared-template initialization barrier. Modes1–3 request no shared memory. The query count aligns both256-thread blocks, so arbitrary partial cooperative blocks are not certified. Duplicates, NaNs, out-of-domain queries and the original eight-million-element CLI are outside the named contract. Float64 template instantiation is a measured supported source-kernel configuration, not a claim that the historical default CLI selected it.

`generate_fixture.py` reproduces95904 exact input bytes. Float32 bits are zero-widened into UInt64 words, and Float64 bits occupy whole UInt64 words; these are lossless encodings, not numeric conversions. `independent_witness.json` checks roundtrips/intervals and records a Float64-query downcast counterfactual separately from the unchanged primary contract. `output_audit.json` checks all20 saved arrays and current executed dependency hashes.

All72 paths are inside each timed suite with five internal repeats; time is divided by5. Compilation warmup precedes five outer trials, whose last four times are averaged. Allocation, reset, copies, CPU oracle and artifacts remain outside. Native precision branches and heterogeneous Julia host dispatch are inside the host-inclusive launch region; no intrinsic abstraction or unprofiled hardware bottleneck is inferred. Source histories, partial proxies and prospective processed-token windows remain separate, with unknown historical consumption unchanged. Root alone commits each verified variant separately.
