IRIS dmem port of all six Hungarian steps. Device symbol arrays are fields of State; managed host control flags are fields of a separate Control data memory. Control is flushed and updated at each synchronous task. Assignment State is flushed at completion. Reduction scratch uses fixed shared storage matching the original maximum, because IRIS tasks do not expose the original dynamic shared launch argument.

Defaults remain user_n=1000, padded n=1024, seed=45345, ten tests. The original _n_/_range_, CHAR_DATA_TYPE and USE_TEST_MATRIX compile controls are supported via EXTRA_CFLAGS. Native HIP reduction helpers are retained for AMD; kernel.cu retains CUDA warp synchronization. Validation compares every total cost, with a permutation check on IRIS assignments. No CPU execution fallback.
