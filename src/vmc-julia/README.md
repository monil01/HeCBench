# VMC: full-population two-electron sampler, named short chains

The native code samples six Cartesian coordinates with correlated trial amplitude (1+r12/2)exp[-2(r1+r2)]. Each walker makes symmetric uniform proposals and accepts according to squared wavefunction values. It accumulates distances r1, r2, r12 and acceptance counts. Although named VMC, this source has no Hamiltonian, local-energy evaluator or variational optimizer; no energy accuracy or full chemical application is certified. Historical Julia is a genuine implementation and is preserved byte for byte.

The study retains the complete57344-walker source population,224 blocks of256 threads, and the224-thread second reduction stage. Two fixed seeds5551212/5551213 use named short burn-ins2/5 and two samples each with3/7 generations. These arguments preserve unchanged native kernel bodies but do not establish the original100000-generation equilibration or5000-generation sample behavior. Chains persist between the two samples and reset seed between cases and trials. All four versions execute five authored kernel entrypoints: RNG initialization, initial configuration, zero statistics, propagation and shared reduction. The reduction uses512 Float32 shared values with source tree offsets128...1 and the224-thread boundary guard. JACC uses dynamic2048 bytes and copies its whole512-element template with an extra entry barrier; CUDA.jl/KA use static shared storage. Other JACC kernels explicitly allocate zero shared bytes. Portable device indexing, shared arrays and barriers use their own frameworks; only CUDA host allocation/synchronization/readback is used. No non-CUDA backend is certified.

Every one of20 saved5057177-word artifacts is fully hash-audited and checked against an independent Float64 oracle using hypot distances, the analytic amplitude, explicit source-rounded random conversion, independent Metropolis chains and mathematical grouped sums. Capture includes all initialized coordinates/wavefunctions/RNG states, all states and four statistics after burn-in and each sample, four reduction totals, the complete224-entry last-statistic workspace, and every actual64-word prefix/suffix guard. Payloads remain256-byte aligned. Exact checks apply to RNG states, perwalker acceptance counts, acceptance reductions and guards; nine scalar input words also match exactly. All actual within-generation intermediate states are not captured: certification covers the declared initialization/burn/sample checkpoints. The native and Julia arrays can differ by small roundoff, which is retained rather than represented as exact equality.

Actual coordinate absolute error is at most7.16e-7, while near-zero coordinate components can have relative errors up to3.37%; no uniform relative-accuracy claim is made. Wavefunction relative error is at most1.93e-6 and accumulated-distance relative error4.29e-6. The largest absolute error .04248 belongs to large reduction totals (relative7.06e-8), not electron positions. The general engineering budget is2e-5+3e-5*abs(reference); wavefunction values have a separately stricter independent budget1e-12+2e-5*abs(reference), preventing small amplitudes from passing merely under a large absolute tolerance. Coordinates, accumulated distances and large global sums have separate metrics in output_audit.json. The Float64 oracle's minimum normalized Metropolis decision gaps are about6.08e-6 and1.67e-6; actual exact RNG and acceptance checks demonstrate agreement on these fixtures, not a formal global branch-stability guarantee. Few-step chain agreement is not a statistical convergence, autocorrelation, confidence-interval or equilibrium certificate. Extreme underflow states are not covered. The source host-normalized printed means and standard-error calculation are outside this kernel-stage contract and remain unverified.

The timed region sums four sample intervals, each zeroing statistics, propagating and executing eight reduction launches:40 total source-shaped launches. Initialization, short burn-in, buffer setup, all full readbacks/oracles/serialization and JIT warmup are outside. Every trial is checked; only timing1 is discarded and2–5 averaged. Per-sample clocks are retained. No actual FLOP, traffic, occupancy or roofline counters were collected. Explicit Julia muladd expresses norm/proposal/prefactor arithmetic; unchanged native nvcc default fusion is not claimed to yield identical instructions. Julia keeps RNG state in local variables then writes it once, while native source expresses global-pointer updates; compiler optimization of actual memory operations was not profiled. Shared-template initialization and dispatch remain mapping covariates.
