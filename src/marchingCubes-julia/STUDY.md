# Marching-block isosurface benchmark

## Scientific contract

The source intends a hierarchical marching-block isosurface extraction, but emits no vertex or triangle mesh arrays. Its observables are active-block counts, vertex/triangle counts, a global index checksum, and four partial-coordinate sums. The actual polynomial uses x,z,z and ignores y, so it is extruded. The original floor-divided grids also crop the nominal N=1024 domain. Both behaviors are preserved rather than replaced by a generic 3D field.

All five GPU stages are ported: coarse min/max, coarse compaction, fine min/max, fine compaction and generation. Active lists are generated on device in every trial; no manual list substitutes for preprocessing. Native device kernels and arithmetic remain unchanged. CUDA.jl/KA/JACC flatten the physical launch geometry while preserving source linear lane order, warp scans and reconstructed coordinates. They use an exact-type shared arena: UInt16 local indices, Float32 values and UInt32 scans. Unconsumed undefined scratch reads are neutralized. JACC adds shared-template reads and a barrier, with explicit scratch sizes 256/128/0/128/1412 bytes. KA/JACC call CUDA device shuffles/atomics/barriers and typed views and are classified as hybrid device intrinsics. CUDA.jl uses its own framework device APIs.

## Evidence and known scientific defect

An independent Float64 CPU field scan, hierarchical selection and table-based cube enumeration reproduces all four counts: 8,296 coarse active blocks, 240,380 fine active blocks, 4,856,560 vertices and 6,101,640 triangles. Each trial checks all 147,968 coarse min/max values, both complete active-ID lists, all 3,733,200 fine min/max values, exact counts, and finite normalized partial-coordinate summaries. Each saved artifact contains 401,053 values; the first 4,401 serialize iso and the actual source lookup tables and are compared byte-exactly, independently of output tolerances. Source/header and generated input-file audits bind those bytes to kernel inputs. Active IDs/counts are also audited exactly; normalized coordinate properties use a predefined absolute 1e-3 tolerance. The fine min/max maximum CPU error is 2.3842e-7.

The source-derived topology audit finds 995 invalid local triangle-index references per repeated y slice. A concrete witness is preserved with original table and ownership values: tile x=98,z=1,y=0, lane98, case102, edge4, local index36 with36 vertices. Boundary masks clear the opposite X/Z ownership bits from their later coordinate use. This is a logical source counterexample, not an observed GPU mesh-array memory failure: no such mesh array exists in this source. Native observable agreement does not certify a scientifically valid mesh. Results carry a known native scientific-defect flag and are excluded from valid-mesh/scientific-fidelity aggregates. The original program's PASS checked only four counts and could not establish these properties.

The global triangle-index checksum varies with atomic assignment of block base offsets. It is recorded raw as a diagnostic, not used as a deterministic full-mesh oracle. Large Float32 coordinate atomic sums also depend on ordering. The accepted four normalized scores are partial fixed-axis and interpolated-axis sums, not full XYZ mesh coordinates or a geometric error metric. Source-derived single-block integer/table witnesses supplement the scalar evidence; they do not upgrade it to mesh-array verification.

## Timings and effort

The original timed region is only generatingTriangles. All four preprocessing kernels, count transfers, allocations, canonical sorting, transfers, CPU checks and serialization stay outside the primary clock. Every process warms the complete pipeline and generation before five synchronized in-process trials; the first trial is discarded and the last four averaged. One frame is generated per trial. Untimed preprocessing durations are retained separately as diagnostics.

Mean generation runtimes are 281.327 ms native CUDA, 301.294 ms CUDA.jl, 295.391 ms KA and 295.427 ms JACC. One slower CUDA.jl retained trial remains in the mean. Source global atomic contention, allocation/alignment, register/spill and occupancy effects have not been profiled; timing differences have no assigned hardware cause.

The archived historical Julia implementation was a touch kernel with hardcoded counts/PASS. Current reference restoration, shared semantic-helper drafting, native adapter, independent fixture/topology oracle, two reference compiler-feedback repairs and one early missing-fixture instrumentation failure are separately recorded. KA and JACC each passed one candidate/check with five kernel wrappers and zero repairs; this reuses the already prepared semantic helpers and does not mean the full benchmark translated in one program attempt. Reference, KA, JACC and annotation windows are separate; the broad workflow overlaps them and is not additive. Consumed usage includes cached/context/coordination tokens and is not exclusive source-generation billing. Historical effort is unknown.
