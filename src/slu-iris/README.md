IRIS dmem port of the six original sparse-LU GPU kernels. RL and RL_perturb use exact static shared variants s32/s4/s2 selected from original MemSize. Original level thresholds, thread/block geometry, TMPMEMNUM=10353, Nstreams=16, input CLI and perturbation formula are retained. All tasks are synchronous in original default-stream order, with resident val/tmpMem marked read-write and only final LU flush. Original NICSLU CPU preprocessing and CPU triangular solve are retained; no GPU vendor solver replacement or fallback.

Set NICSLU_ROOT to an existing unchanged NICSLU build, or let make extract the bundled original archive into untracked .deps, excluding the external demo/matrix symlink. No extraction or clean touches CUDA/HIP siblings or an external NICSLU root. make run keeps default demo/ASIC_100k.mtx; make test uses original test/add32.mtx. VERIFY=yes by default preserves ABFT. Optional SLU_VERIFY_DIR exports complete factors, solution and symbolic structures for validation; original x.dat output is unchanged. CUDA backend is included but not locally validated.
