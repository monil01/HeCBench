# PRESENT IRIS DMem
Original seed 8, random 80-bit keys, repeatedly shuffled PRESENT text, 31 rounds, repeat+1 launches (first excluded from timing), checksum and default 100000 100 are preserved. Eight DMem buffers replace native GPU allocations. Output flushes after every launch support original checksum accumulation. Complete ciphertext byte checks against the unchanged host reference and per-launch hashes strengthen verification in both local HIP instrumentation and IRIS. Actual HIP GPU required. IRIS task overhead is included in timing. CUDA kernels provided but not locally tested.
