IRIS data-memory port of the event-driven GPU simulator. Live input histories, gate input offsets and output histories are flattened into directly tracked buffers. All output histories, sizes and overflow flags are flushed before retry growth or SAIF printing. The original gate simulation algorithm, 32-thread blocks, history growth schedule, input files, dump range and SAIF output are preserved.

The original input explicitly selects a hybrid schedule (StartCPU=23 of 109 blocks). Its 23 GPU blocks run through IRIS HIP; the original remaining CPU tail remains part of the benchmark and is not an execution fallback. No added CPU fallback for GPU blocks. Native CUDA/HIP sources are unchanged. Use IRIS_ARCHS=HIP make run. Verify complete SAIF net durations against native HIP in isolated output paths.
