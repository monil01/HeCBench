Preserves repeat argument, fixed Params geometry, srand123 initialization and original box/score verification (1e-3 box tolerance,1e-6 score selection). One DMem task launches the original HIP kernel with six anchors per block. Box input is iris_rw and refreshed from unmodified host input each iteration; counter is iris_rw and DMem.update(zero) each iteration. Host box input is not flushed because CPU verification decodes that original input. Box/score/counter outputs are flushed. make run keeps10000 repeats; bounded validation runs1 and2. Atomic output ordering is nondeterministic as in native HIP, so compare PASS/count/reference values rather than raw array hashes. Timing includes IRIS overhead.
