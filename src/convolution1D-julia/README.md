# convolution1D: three real zero-padded FIR strategies

The named study covers all three unchanged native algorithms (basic, full halo tile, cached centre), five block geometries64–1024, mask widths3/5/7/9 and actual Float64/Float32/Int16 arithmetic at2048 cells. Two fixtures produce360 paths. Original Julia basic-kernel code is preserved; two genuine tiled variants replace the historical labels that called the basic kernel. Native source and all old Julia/Makefile bytes remain preserved.

The source operation follows coefficient order: y[i]=sum x[i-floor(MW/2)+j]*m[j] with zero padding, without reversing the mask. The source's all-ones fixture hides orientation; the predeclared signed/asymmetric operator fixture exposes it. Input and coefficient values are bounded integers, making every product/partial sum exact in all three types without Int16 overflow. This does not validate arbitrary fractional rounding or overflowing input ranges. The canonical fixture reproduces the current host libc srand123/rand%256 source initialization; the frozen binary is authoritative if another libc differs.

`fixture.bin` stores12432 UInt64 words containing actual Float64/Float32/Int16 input/coefficient bits. Physical GPU outputs are computed in their declared types and losslessly widened to Float64 for exact UInt64-bit artifacts. Every trial retains755472 words, including737280 output values and5760 exact typed guards. `independent_witness.json` compares independent gather/scatter oracles and orientation/periodic-boundary counterfactuals. `audit_saved_outputs.py` rechecks every saved artifact against an independent input-scatter oracle, input bits, guards, mean2–5 and current source hashes without running a GPU.

Each of five outer trials sums24 kernel-batch regions, each containing15 algorithm/geometries repeated3 times and a completion sync; each batch time is divided by3. Parameter uploads, mask readback, resets, input transfers, CPU checks and output capture are outside every region. Compilation warmup precedes all trials; only trial1 timing is discarded. This is a named grouped launch cost, not original CLI time or one kernel's latency/roofline.

Native coefficients retain physical CUDA constant memory; Julia uses global device coefficient arrays. This is a disclosed storage mapping, not a claim that a framework universally cannot express constant storage. Tiled/cache kernels use one barrier in native/CUDA.jl/KA; JACC adds its full shared-template initialization barrier. JACC shared bytes are explicit per type/geometry, never the default48KB. Hardware resources/cache/traffic remain unprofiled. Julia heterogeneous host dispatch and JACC cached dictionary lookup contribute to the actual timed launch region.
