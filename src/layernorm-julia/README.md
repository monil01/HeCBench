## Algorithms and exact controls

All three native algorithms are retained: block-per-row two-pass reduction with true alignedFloat4 loads/stores whenCdiv4 and scalar otherwise; warp-per-row two-pass central variance; and warp-per-row moment variance mean(x^2)-mean(x)^2. Every algorithm runs all block widths32/64/128/256/512/1024. Six bases use(rows,channels)=(5,256),(7,259),(3,1024), each with bounded textured inputs and exact constant rows. Gamma includes zero and negative values, beta varies. There are108 paths with partial row groups and a scalar channel tail.

All versions retain the Float32 XOR reduction network, FMA variance/affine arithmetic, reciprocal square root, physical16-byte vector path and streaming load/store hints.
