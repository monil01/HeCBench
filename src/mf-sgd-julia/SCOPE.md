## Numerical evidence class

**Property equivalence, not literal cross-process model equality.** Original parallel Hogwild permits competing writes to shared FP16 factor coordinates. Retain all actual initial/final factor bits, transformed/scaled/unshuffled model values and every train/test prediction, together with physical guards and actual device inputs. Never replace raw factors with only a summary and claim numerical model identity.

All actual seeded selector starts and final worker RNG states are checked against independent exact modular/FP32 arithmetic; source update counts/selected record coverage are retained. Read-only observer trace stores may be added uniformly to the update kernel and disclosed as instrumentation, without ordering factor updates or changing their arithmetic. Four independent-warp single-update controls with source kernel parameters explicitly restricted to one vector element validate the same rank128 dot/reduction/gradient/half-rounding operator against independent higher precision. These controls are diagnostic operator witnesses, not substitutes for the full parallel training pipeline.

Primary per-model checks (declared before current full training): all defined actual inputs, guards and model/prediction values finite; seeded selector trace exact; factor values change from initialization; independently recomputed **training squared-error sum decreases strictly from the identical initialized model**, and full held-out raw-rating RMSE is **at most3.0**. These are finite named-input property criteria, not guarantees for arbitrary SGD, proof of matching stochastic trajectories, convergence or recommendation accuracy. Prediction/dot roundoff is bounded from the actual operation count/inputs; unit gradient quantization uses a declared FP32-operation plus FP16-rounding bound, not tolerance fitted to failed outputs. Any failed original criterion remains archived.
