# SA research observations

- **RQ1:** Complete unique suffix-order certificates and exact four-way input/output/guard bytes pass for the real million-symbol genomic prefix and fourteen controls. This validates the indexing operator, not biological alignment quality. The source checksum alone was insufficient evidence.
- **RQ2:** One authored GPU math bundle per target, nine custom entries each. CUDA.jl needed one host pointer-conversion API repair; JACC one generator-whitespace frontend fix. Neither reached custom device JIT before its repair. Device compiler and numerical repairs: zero observed. Actual context/cache-inclusive token windows remain separate from native preparation, shared verification and annotation; inherited architecture/harness scope is explicit.
- **RQ3:** Mean runs 2–5 per construction: native 29.1206 ms, CUDA.jl 28.8980 ms, KA 29.0130 ms, JACC 30.8657 ms. All five are checked; no fastest-run selection. ROI includes source transfers, Thrust workspaces/sorts/scans, device rank readback, recursive host control and final transfer. Control timings are excluded from aggregates.
- **RQ4:** All three custom device components are framework kernels. The whole measured program is hybrid host control with library operations: a device-derived rank determines recursion. Native/Julia host dispatch, nonowning views, C ABI and GC differ. No profile counters or controlled attribution establish the cause of the timing differences or a roofline position.
- **RQ5:** Backend choice must include an interoperation strategy for sorting/scanning/containers and host feedback, not just elementwise kernel syntax. Retaining source Thrust operations is a fidelity choice, not evidence that KA/JACC lack sorting capabilities.

The original GPU mathematics is unchanged. External guards, warm protocol and shared runtime linking are explicit integration adaptations excluded from untouched-native aggregates. Only the final of each R100 construction sequence is archived per trial; private workspaces and every internal output are not claimed. Full source and every actual trial remain preserved.
