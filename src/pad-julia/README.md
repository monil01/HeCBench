# PAD: source-faithful static CPU/GPU in-place padding

This named study preserves the original native GPU and CPU bodies. All four models use the same original C++ CPU worker through a source/compiler-hash-keyed shared library; CUDA.jl, KA and JACC genuinely implement the GPU private-load/barrier/atomic-flag/in-place-store algorithm. This is an explicitly hybrid program, not a pure Julia CPU translation. The historical Julia out-of-place padding source and Makefile are preserved byte-identically in reference_history.

Two legal, tile-aligned Float64 shapes (256×127 with one padding column, 256×503 with nine) are evaluated at Float32 alpha 0, .1, .25, .5, .75, 1. Actual CPU tasks are truncated Float32 products, not exact requested fractions; alpha .1 of four tasks owns zero CPU tasks. Source grid8, threads256, REGS32 and four CPU workers are retained. GPU blocks can persist through multiple8192-cell tasks. Dynamic/system-atomic partitioning, arbitrary oversubscribed grids and the original full CLI are unverified. Nonaligned alpha0 host-prefix bounds are documented as a static source risk without executing undefined input.

Each of five checked trials sums twelve path regions, each with three fresh-reset pipeline repetitions. Reset/backup copy, flags, H2D prefix/flags, GPU launch, CPU coordinator plus four worker spawns, GPU completion and CPU join are timed. Allocation, explicit full-pipeline compilation warmup, final D2H merge and validation are outside. Trial1 timing alone is omitted from the mean. Actual CPU/GPU overlap is unknown, not inferred from asynchronous launch order. Alpha0 still creates empty CPU workers and alpha1 launches empty GPU blocks. All12 path durations are retained for eachtrial; path_timing_summary.json reports every mean2–5 and endpoints separately. The first valid aggregate-only adapter series is retained as history; v2 is selected for better measurement granularity, not speed, with all4 models remeasured. No GPUkernel or numericalcontract changed.

Each raw UInt64 artifact has 1,147,828 words: 163,948 exact initial Float64 bits and parameter words, plus all padded outputs, host/device guards and complete CPU/GPU dependency flag images. Signed zero and subnormal copies are checked bitwise. `audit_saved_outputs.py` constructs an independent input-scatter oracle and independently enumerates/increments task flags; it checks saved arrays without any GPU runs. `scientific_witness.json` records the load-before-store flag-chain proof and support restrictions. JACC explicitly requests zero shared memory; private register/spill/occupancy behavior is unprofiled.

CPU component build identity, compiler flags and loaded library SHA are in build/runtime logs and the immutable local CPU-component cache. Prospective usage windows include repeated/cached context, coordination and local witnesses, overlap the workflow window, and do not recover historical Julia translation cost. All first target candidates/checks passed.
