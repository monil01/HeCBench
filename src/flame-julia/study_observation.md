# flame: conditional true-half fractal point generation

This is a fractal-flame renderer component, not combustion or thermal simulation. Source code describes a randomized iterated-function system producing geometry/color vertices. The historical Julia program is preserved intact in reference_history: it used different nonlinear formulas, arithmetic permutations and Float32 state. It is not treated as a verified native-equivalent reference. All original native files and GPL license are archived intact.

## Native storage defect and preserved evidence

Modern CUDA converts __half to short numerically. Original kernels assigned __float2half_rn results to short/short2 fields and later called __half2float on those integers. A CPU witness shows0.75->short0->0, rather than half bits0x3a00->0.75. A complete unchanged-native N16384 frame(init+15iterate+64points/thread) confirms every initialized/final stored color is0. Intended true-half initialization colors are0.75/0.25/approximately0.45; minimum/maximum bias0.25/0.75. All1,048,576 emitted vertices are finite and their colors match the actual integer-storage source semantics. This is an intended precision-contract defect, not a fabricated GPU crash or undefined-memory claim. Raw inputs/state/vertices are retained locally with hashes in original_native_quantization_audit.json. Original diagnostic buffers had no guards; no guarantee is invented for them.

The corrected-reference secondary changes selected point/color pointer/local types from short2/short to __half2/__half, preserving4/2-byte strides and all iteration.cu formulas. The exact patch is retained. It is explicitly native_reference_repaired and excluded from untouched-CUDA aggregates. Default nvcc-O3 arithmetic remains enabled; no-fmadfalse flag was used. Compile-only PTX guided matching of affine/accumulation FMA grouping in Julia. This correction is separate from a named compile-time size specialization to N256/random1024/permutations128. Original full CLI performance/physics/image quality is not certified.
