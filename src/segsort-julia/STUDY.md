## Scientific and numerical scope
This is a domain-neutral segmented ordering primitive, not an application quality benchmark. The measured named fixture has357548 Int32 keys in376 variable-length segments, including12 empty segments and every source bin0–12 with lengths up to5000. Both keys-only duplicates/negative values and unique-per-segment keys with actual full UInt64 high-bit payloads are measured. Original default2^25 throughput scale is unmeasured.
