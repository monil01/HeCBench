Half2 is real packed2xFloat16 storage/arithmetic, expressed through CUDA add.rn.f16x2/fma.rn.f16x2 backend instructions inside genuine framework dispatch. This path is explicitly hybrid, not a pure portable half2 API or two scalar-half substitute. Scalar Float32/Float64 use ordinary Julia muladd. Shared generated helper unrolling preserves nominal source operation count while being authored once during reference restoration and reused by targets. No unsupported-framework claim is made.
