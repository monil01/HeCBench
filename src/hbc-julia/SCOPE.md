# HBC declared study before GPU evaluation

The scientific operator is exact-source unweighted undirected vertex betweenness centrality (Brandes), not an approximation to a physical field. The source is Georgia Tech's hybrid BC algorithm: one CTA per SM, 1,024 threads on the V100, dynamic source scheduling, frontier/edge traversal, UInt64 shortest-path counts, Float32 dependency and atomic centrality accumulation, and adaptive diameter/bitonic selection after source index1,024. The complete exact/default kernel and its bitonic helper will be retained; no vendor BC or CPU substitute.

Named input scope is the exact recovered source `breast_coexpress.txt` dataset (7,819 vertices,195,928 undirected edges) plus synthetic path, fractional multipath and >512-frontier controls. The declared archive is independently MD5/size checked before use. The source original parser will be used by native, its exact lexicographic-ID CSR echoed by all versions. Self/multiple edges are excluded as required by the source. Optional approximate source sampling and arbitrary weighted/directed graphs are not verified. Source approximate-mode post-workqueue terminal index fetch is a source-observed unmeasured memory-safety concern, not a demonstrated exact-mode failure or framework limitation.

Native source device bodies remain unchanged. The ROI is the source's internal timed kernel launch plus whole-device completion; allocation, pitch preparation, source upload, zeroing, actual-input readbacks, all raw output/workspace/guard captures and CPU verification are outside. This is not the source main's allocation-inclusive outer timing. A full warmup precedes five independently reset checked trials/model. Keep only the mean times2–5, retain all five correctness verdicts.

Pre-GPU acceptance will be derived from an independent long-double Brandes replay, maximum shortest-path counts, maximum eccentricity and degree. All integer CSR/initial device inputs and path counts must be exact; no silent overflow or Float64 integer rounding is allowed. Positive Float32 dependency/centrality error budgets must be written before the first GPU measurement. Full BC values, actual initial input bytes, actual per-buffer guard bytes and full pitched final workspaces are retained; dynamic CTA last-source assignments/queue order need independent source-specific checks, not fabricated raw equality.

The adaptive jia flag/diameter telemetry is retained as actual source scheduling behavior, not forced to manufacture the same optimization choice. Both traversal branches compute the same mathematical operator. No biological discovery, causal gene-network interpretation, universal scaling or roofline bottleneck is established by centrality agreement.
