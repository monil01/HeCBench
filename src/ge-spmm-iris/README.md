IRIS tasks use DMem only. Dynamic shared storage becomes static storage for up to32 tile rows (1024 threads, source device limit). HIP syncwarp matches native header behavior. Validation uses a bounded MatrixMarket fixture with empty rows, long rows and partial tiles. Isolated native compiles the original HIP host against the same CUDA utility/header sources referenced by its original Makefile; native siblings are untouched.
