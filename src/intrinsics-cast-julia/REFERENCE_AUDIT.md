# Native initializer and historical reference audit

The unchanged original host loop starts at1 and writes through n. For a logical n-element allocation it leaves input[0] uninitialized and writes input[n] out of bounds. The deterministic n=1 guard-slot witness copies this literal loop into a physically two-element buffer: logical element0 remains sentinel, guard slot1 changes to source values. This is a safe logical-boundary witness, not a claim to have rerun the original program under an address sanitizer. The original CLI/full initializer is defective and is not numerically certified.

The study includes unchanged original CUDA device kernels under a renamed main and loads a new fully initialized shared canonical fixture. It uses65536 entries, source22.44/(i+1) floating values and constant0x403670A3D70A3D71 integer values. Both native timed regions are separate configurations. This named fixture does not repair or certify the original native CLI.

Historical Julia omitted most conversions/rounding modes and printed fixed checksums, followed by unconditional PASS. Its source is archived. Current reference restores both source device programs and checks every Int64 output against independent Python IEEE rounding/bit-semantics artifacts and native outputs; no checksum string is correctness evidence. Directed conversion helpers explicitly call CUDA libdevice ABI, so Julia-family implementations are CUDA-backend-specific hybrid device intrinsics, not portable generic math. Individual intermediate intrinsics are not exhaustively conformance-tested; exact aggregate source outputs are checked.
