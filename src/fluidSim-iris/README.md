IRIS DMem port of the CUDA lattice-Boltzmann fluid simulation. Build with make; run with IRIS_ARCHS=HIP make run RUN_ARGS=3. Default 256x256 cells, 10000 iterations, seed 123, omega and original verification are preserved. Ping-pong output buffers use iris_rw to retain boundary distributions; initial host copies explicitly update DMem. Optional HECBENCH_DUMP_OUTPUT writes all nine double distributions per cell for full-array native HIP comparison; it does not change the simulation or reference checks.
