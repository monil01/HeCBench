RQ1: All three real Julia versions preserve the full 19-state, 53-parameter source operator. A preliminary derivative defect claim was refuted, not counted as a native failure. JACC required one host launch-geometry feedback repair after the full-state oracle detected stale cached block counts.

RQ3: Mean trials 2–5: native 0.0403569625 s, CUDA.jl 0.069950611 s, KA 0.069607403 s, JACC 0.069169052 s. These are summed three-case, 201-launch regions from one block/model; no isolated large-case throughput, confidence interval or causal abstraction inference.

RQ2: Prospective target workflow windows and separate native/annotation windows are preserved in JSON. Counter totals include cached context, coordination, verification waits and inherited session context; they are not exclusive coding tokens or billed costs. Nested verification counters are not additive. KA/JACC reuse validated common mathematical body.

RQ4: Local cardiac ionic ODE integration (0D), within continuum/constitutive family, without spatial diffusion. Float64 storage and arithmetic; one independent cell/thread and no shared memory. No performance-counter evidence establishes a bottleneck.

RQ5: All actual GPU inputs, all 19 final and replay-first-step state fields, guards and read-only parameters checked. Independent affine gate/receptor closed forms complement common-source CPU comparison. Named full Makefile 100×100000 run is included; million-step CLI, complete action potentials, tissue and clinical validity remain unmeasured.

Canonical paper mapping: RQ1 fidelity; RQ2 feedback/effort/tokens; RQ3 execution/performance; RQ4 mechanisms/ontology; RQ5 scoped selection. Scientific witnesses support the named operator only, not a universal framework recommendation.
