# warpexchange IRIS DMem
All GPU memory is IRIS DMem; each repeated exchange is a separate synchronous IRIS task followed by an explicit output flush. The kernel preserves the source's 256 threads, four items/thread, 32-thread logical warps, block-direct load/store helpers, and original grid/tile loop. The existing HIP sibling's wave-lockstep/shared-memory implementation is retained for gfx908 (not claimed portable to arbitrary divergent hardware).
Original rows/columns/repeat arguments, sequential integer inputs and default 8192 8192 100 are unchanged. Original complete-warp difference verifier is retained; an additional exact elementwise mapping check and full-output byte hash support HIP comparisons. As in the source, partial 128-item warps can consume undefined out-of-range registers: they are explicitly reported as not fully verified. Tests use complete logical warps, including incomplete 1024-item tiles.
Build with make; run IRIS_ARCHS=HIP make run RUN_ARGS="129 128 2". IRIS must detect a HIP GPU. Timing includes synchronous IRIS submission overhead. CUDA source is provided but not locally validated.
