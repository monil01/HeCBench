# Scientific families for the active 447-name study

The frozen 300-name census keeps its original eleven-family classification. The active study adds `quantum_electronic` when a source review identifies electronic structure or quantum many-body scientific intent, such as GPP's BerkeleyGW plasmon-pole self-energy component. This is a source-backed extension of the study ontology, not a retroactive reclassification of the frozen cohort.

| Family | Scientific or reusable component scope |
|---|---|
| `pde_continuum` | Discrete continuum, constitutive, and field operators |
| `particle_molecular` | Particle and molecular interactions |
| `quantum_electronic` | Electronic structure and quantum many-body components |
| `signal_image` | Signal, image and rendering operators |
| `geometry_robotics` | Geometry, coordinates, kinematics and point-set operators |
| `linear_algebra` | Matrix and vector algebra primitives |
| `stochastic_statistics` | Statistical and stochastic sampling components |
| `machine_learning` | Learning and attention operators and their data preparation |
| `graph_irregular` | Graph and irregular combinatorial workloads |
| `discrete_crypto` | Discrete, coding, cryptographic and explicitly noncryptographic hashing primitives |
| `hardware_data_movement` | Hardware behavior, collectives, control and data movement |
| `domain_neutral_primitives` | General primitives without a demonstrated application domain |

Select one primary family using reviewed scientific intent and preserve secondary domain/motif tags. A physical-sounding benchmark name is insufficient evidence. Keep `unclassified` for pending intent review. Domain classification does not certify physical prediction: name the finite operator, arithmetic, fixture, boundary, independent oracle and application-level claims that remain untested. Implementation models, actual Julia/package/toolchain versions, library interoperation and measured performance descriptors remain separate records.
