\paragraph{Neighbor lookup time includes data movement} The KNN timed closure allocates/uploads, computes pairwise distances, sorts stable neighbor indices, applies square roots, downloads and frees. Kmeans instead sums selected transpose/iteration transfer-and-host-update/RMSE windows. Both are neighbor/cluster operators, but neither reported time is simply summed GPUkernel time; sampled intensity cannot be divided into those host-inclusive rates without full phase evidence.

\paragraph{Moment reduction is not normalized kurtosis} This source returns count, mean and unnormalized central sums through fourth order, using a custom merge result with Float32 fields. Julia operation windows also allocate reduction buffers and copy/free the result per repeat. Native uses Thrust/CUB; its unresolved kernel-family selector is withheld rather than assigned from API naming alone. A Float64 serialized artifact does not make the moment accumulator Float64.

\paragraph{The operator name is not a trajectory model} The source evaluates the scalar Langevin function coth(x)-1/x using two hyperbolic formulas and an explicit FMA polynomial. The timed loop visits all three formulations for two input fixtures; source-fidelity checks and mathematical-function error policy must remain distinct. This evidence describes special-function evaluation, not stochastic dynamics, and a different instruction mix would be a measured association rather than proof of a bottleneck.
