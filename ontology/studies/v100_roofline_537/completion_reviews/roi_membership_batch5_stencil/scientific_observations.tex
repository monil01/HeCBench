\paragraph{A sampled kernel can belong to excluded setup} Both source paths compute backward links before starting the Dslash timer. Those source call sites are excluded, while the hopping callback is included. A profile can nevertheless sample make\_back/back\_kernel during warmup/setup. Source-family inclusion therefore cannot establish actual sampled phase or justify joining all sampled counters with the reported primary mean.

\paragraph{A differential operator can have a host-inclusive timer} The NP4 divergence timer encloses contravariant transformation, allocations, transfers, the divergence kernel and reclamation. Its device instruction intensity describes the sampled kernel, not the elapsed workflow rate. The restarted eigenvalue timer similarly includes host convergence checks and transfers, as documented by its separate source proof.

\paragraph{Scientific output storage does not determine counted FLOPs} The extrema contract visits Int32/Int64/Float32/Float64 inputs but produces Boolean comparison masks; ordinary add/multiply/FMA work must come from actual counters, not its input type. Conversely, DXT compression emits packed integer words after floating endpoint search and integer packing. Storage/output type is separate from executed precision and scientific semantics.
