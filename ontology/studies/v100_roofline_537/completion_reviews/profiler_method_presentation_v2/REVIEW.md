## Concrete changes

1. Plot titles contain a separate one-line compact version label, obtained from an explicit version/release token or whitespace-collapsed shortened text. Raw exact version strings remain in profiler_strata, publication_selection and each point/exclusion identity. Top-level title .99, identity .958 and scope .938 have distinct lines. This layout is source-reviewed only; rendering remains a later root check.
2. The canonical stratum key is the full SHA256 of JSON ASCII tuple (method ID, exact unabridged version text, method review SHA), serialized with separators ',' and ':'. Both plot and publication exporter use the same implementation. Changing raw version whitespace deliberately changes identity. Human display is never the joining key.
3. Both plot and publication exporter accept --publication-stratum EXACT_SHA256. More than one compatible/positioned stratum with no explicit selection raises with the available exact identities before writing canonical output. A nonexistent requested stratum also raises. Exactly one stratum may be selected implicitly and is labeled selection='unique'; zero observations yields no canonical figure. No first-sorted fallback exists.
4. Every stratum has its own plot filename. The V1 Path.with_suffix bug would have removed '.method_TAG' and overwritten strata; v2 appends .pdf/.svg instead. The selected stratum is also copied to the legacy canonical basename with exact file hashes and selected identity recorded. Method-stratified diagnostics are not overlaid. The canonical PDF contains only the selected stratum; top-level metadata counts still describe all diagnostics and must not be mistaken for canonical counts (use selected stratum's plotted_rows).
5. Publication coverage/status counts keep all 537x4 slots. Geometric prediction rows are restricted to the selected stratum and carry method/version/review identity. Completed observation counts remain descriptive all-strata counts, with a separate per-stratum counter. Future native comparisons require complete, equal method/version/review identity before existing phase/aggregate gates. Unknown identity never authorizes a comparison.
6. Refresh forwards the explicit CLI choice to both consumers. Plot outputs are generated in a new temporary directory; failure never selects old PDF bytes. Before attempting refresh it invalidates both canonical authority manifests under the metadata lock. On success, it rechecks plot scalar/tensor input hashes or every publication bound input under LOCK_EX before copying outputs and committing SHA-bound authority. A crash, ambiguous selection, zero compatible points or changed input leaves current authority unavailable. Old files remain historical evidence, not current consumer authority.
7. Explorer gains selected/native identity columns and graph gains method/version filters and exact review details. Current scalar applicability verification and keys remain byte-preserved in the rebased context. Graph similarity weights are untouched and remain descriptive.

## Mandatory consumer contract

Canonical figure consumers must read figures/canonical_figure_manifest.json under LOCK_SH, require canonical_available=true, verify its metadata SHA, current scalar/tensor input hashes and every canonical output SHA, and use only the manifest-selected paths/stratum. A bare legacy PDF path is not an authority. Publication consumers similarly require publication_selection_status.json current_export_available=true and verify the exported file hashes and selected identity. The refresh uses the same explicit CLI choice for plot and publication; differing compatible row populations may make one refuse the choice, which is a hold, not permission to substitute another stratum. Consumers must not interpret all-strata coverage totals as selected-stratum positions.

The existing repository search found the live refresh is the direct plot/publication command consumer. No current paper Python/TeX direct reference to normalized_kernel_rooflines was found. Legacy external consumers of a bare figure path are outside that bounded search and must adopt this manifest contract before use. No stale-output fallback is acceptable.
